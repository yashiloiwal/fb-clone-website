# 🚀 Facebook Clone

A lightweight Facebook clone created to master **Git** and version control workflows, while building out basic social media interface components.

---

## 📌 Features

* **User Feed:** View posts with text content and user interactions.
* **Interactive Elements:** Like, comment, and share post functionality.
* **Navigation Bar:** Global search bar, quick links, and profile settings dropdown.
* **Sidebar Navigation:** Quick access to Shortcuts, Friends, Groups, and Marketplace.

---

## 🛠️ Tech Stack

* **Version Control:** Git, GitHub
* **Frontend:** HTML5, CSS3, JavaScript

---
